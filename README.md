# adidas-sales-performance-analysis-powerbi
Interactive Power BI dashboard analyzing Adidas sales data to uncover revenue trends, product performance, and regional insights.
##  ObjectiveThe objective of this project is to analyze Adidas sales data using Power BI to identify revenue trends, product performance, regional sales distribution, and customer insights. The goal is to transform raw sales data into interactive visualizations that support data-driven decision-making and improve business strategy.


-  <a href="https://in.docworkspace.com/d/sIO-v5PGDAZqugs0G?sa=601.1037"> Dataset</a>

  KPIs Used

Total Sales → Overall revenue generated

Total Profit → Net profit from sales

Total Units Sold → Number of products sold

Profit Margin (%) → Profitability of sales

Sales Growth (%) → Increase/decrease over time

Average Sales per Order → Revenue per transaction
